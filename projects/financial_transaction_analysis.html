Case Study

Financial Transaction & Customer Behavior Analytics

Developed an end-to-end Python analytics project using 13.3M financial transactions worth $571.84M to evaluate transaction performance, spending patterns, merchant activity, customer behavior, transaction methods, geographic patterns, card usage, and transaction errors. The project transforms large-scale transactional data into business-focused insights while carefully accounting for data limitations.

Financial Services & Customer Analytics Python · Pandas · NumPy · Matplotlib
View GitHub

Project Overview

This project is an end-to-end Financial Transaction & Customer Behavior Analytics solution developed in Python.
The analysis covers 13,305,915 financial transactions recorded from January 1, 2010 through October 31, 2019, representing approximately $571.84 million in transaction value across 1,219 active customers and 4,071 active cards.
The project combines transaction, customer, card, merchant-category, and limited fraud-label data to evaluate transaction performance and understand customer financial behavior. The goal is to transform large-scale transactional data into clear, business-oriented insights while communicating important analytical limitations.

Business Problem

Financial transaction data spans multiple dimensions, including customers, cards, merchants, transaction methods, categories, locations, amounts, and transaction outcomes.
Without a consolidated analytical view, it is difficult to understand overall transaction performance, identify meaningful customer behavior patterns, compare transaction channels, evaluate merchant activity, and detect areas requiring operational attention.

Project Objectives

The objective of this project is to develop a structured Python-based analysis that helps understand:

  • Overall transaction value, volume, and average transaction size.
  • Transaction trends and spending patterns over time.
  • Swipe, chip, and online transaction behavior.
  • Merchant-category performance by transaction volume and value.
  • Geographic transaction patterns.
  • Transaction errors by error type and transaction method.
  • Customer spending, activity, financial characteristics, and card usage behavior.

Business Questions

  • What is the overall transaction performance across the dataset?
  • How do transaction volume, value, and average transaction size change over time?
  • How do transaction amounts and transaction methods differ?
  • Which merchant categories contribute the most transaction volume and value?
  • Where is transaction activity geographically concentrated?
  • What transaction errors occur most frequently, and how do error rates differ by transaction method?
  • How active are customers, and how does customer spending vary?
  • How concentrated is transaction value across customers?
  • How do customer transaction methods, merchant preferences, financial characteristics, and card usage differ?

Analytical Approach

Extracted, cleaned, transformed, and merged large-scale transaction, customer, card, and merchant-category data in Python, then performed exploratory analysis, visualization, customer-level aggregation, and business-focused interpretation.

Analysis Highlights

The analysis is organized around financial transaction performance and customer behavior. Key measures include total transaction value, transaction count, average transaction value, active customers, active cards, transaction-method mix, merchant-category activity, geographic patterns, transaction errors, customer spending, and card usage.
The dataset contains 13,305,915 transactions with approximately $571.84M in total transaction value and an average transaction value of $42.98.

Key Insights

Swipe was the dominant transaction method by volume, accounting for 52.36% of transactions, followed by chip at 35.93% and online at 11.71%. Online transactions, however, recorded the highest average transaction value at $57.26, compared with $41.21 for swipe and $40.89 for chip.
Merchant-category analysis showed that transaction volume and transaction value tell different stories. Grocery Stores and Supermarkets generated the highest transaction frequency, while Money Transfer generated approximately $53.2M in transaction value and ranked first by value.
Among identified states, California recorded the highest transaction value at approximately $59.08M, followed by Texas at $42.48M and New York at $39.72M. Online and unknown-location activity was treated separately from physical geography to avoid misleading geographic conclusions.
Approximately 98.41% of transactions had no recorded error, while 211,393 transactions, or 1.59%, contained an error. Insufficient Balance was the most common recorded error. Online transactions had the highest observed method-level error rate at 2.28%, compared with 1.51% for chip and 1.49% for swipe.
Across 1,219 active customers, average cumulative spending was approximately $469,102 while median cumulative spending was approximately $398,837, indicating that higher-spending customers raise the overall average. Customers averaged approximately 10,915 transactions across the full multi-year observation period.
Card usage was led by Mastercard with 53.79% of transaction volume, followed by Visa with 37.26%. These raw transaction counts reflect observed card activity and should not be interpreted as direct evidence of customer brand preference.

Business Impact

The analysis provides a consolidated view of transaction performance and customer behavior across transaction channels, merchant categories, geography, customer activity, and card usage. It demonstrates that transaction volume and monetary value should be evaluated together, because high-frequency categories and channels do not always generate the highest transaction value.
The customer-level analysis also highlights differences in spending and activity that can support behavioral segmentation, while transaction-error analysis provides a basis for identifying channels and error types that may require closer operational monitoring.
